# CleanRSP
Телеграм-бот, разрабатываемый с упором на чистую архитектуру и максимальную производительность в многопоточной среде.

## Технологический стек
* **Язык:** Python 3.14t (Free-threading / экспериментальная NoGIL сборка)
* **Инфраструктура:** Изолированное виртуальное окружение.

## Локальная настройка окружения
Для корректной работы необходимо использовать интерпретатор версии 3.14t.   
Интерпретатор необходимо скачать с официального сайта Python.org.   
В процессе разработки проекта использовался Python 3.14.5rc1 - May 4, 2026  

1. Создание виртуального окружения:

    `python3.14t --version`

    `python3.14t -m venv .venvt`
2. Активация:
   
    `source .venvt/Scripts/activate` (для Bash)
3. В IDE преднастроенный интерпретатор удаляется, а созданный указывается локально:

    `.venvt/Scripts/python.exe`
4. Обновление менеджера пакетов:

    `python -m pip install --upgrade pip`
